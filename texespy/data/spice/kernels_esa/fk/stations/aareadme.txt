Brief Summary
--------------------------------------------------------

     This directory contains the SPICE Frames Definition Kernel files for the
     Ground Earth Stations.
   

Current FK Kernels Set
--------------------------------------------------------

   estrack_vNN.tf

      SPICE FK file that provides topocentric frames for the ESA Ground
      Stations. Created by the ESA SPICE Service.


   new_norcia_topo.tf

      SPICE FK kernel for the topocentric reference frame for the ESA 35m
      tracking antenna at New Norcia.


   earth_topo_050714.tf

      SPICE FK kernel for the topocentric reference frames for the Deep Space
      Network (DSN) stations. This kernel was released on the date indicated
      in the filename.


   earthstns_ru_YYYYMMDD.tf

      SPICE FK file that contains definitions for topocentric reference
      frames for the Russian ground stations. Created by IKI.
