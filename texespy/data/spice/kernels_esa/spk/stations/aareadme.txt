Brief Summary
--------------------------------------------------------

     This directory contains Solar System Generic SPICE SP-Kernel files
     including Ground Earth Stations locations.


Current SPK Kernels Set
--------------------------------------------------------

   earthstns_fx_YYMMDD.bsp

      SPICE SPK file containing ephemeris data for NASA DSN stations relative
      to the terrestrial reference frame label 'ITRF93'. This file was released
      the 14th of July 2005 by NAIF, JPL.


   earthstns_itrf93_YYMMDD.bsp

      SPICE SPK file containing ephemeris data for NASA DSN stations relative
      to the terrestrial reference frame label 'ITRF93'. This file was released
      the 14th of July 2005 by NAIF, JPL.


   estrack_vNN.bsp

      SPICE SPK file that defines the position for each of the ESA ESTRACK
      ground stations, as seen from the center of the Earth, in the
      topocentric frame defined in the corresponding ESTRACK FK. Created
      by the ESA SPICE Service (ESS).


   earthstns_ru_YYYYMMDD.bsp

      SPICE SPK file that contains the position for each of the Russian
      ground stations relative to the center of the Earth. Created by IKI.


   new_norcia.bsp

      SPICE SPK file that defines the position of the ESA New Norcia
      ground station, as seen from the center of the Earth, in the
      topocentric frame defined in the corresponding New Norcia FK.
